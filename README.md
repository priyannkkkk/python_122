# 🎥 Movie Franchise Data Analysis

Welcome to the **Movie Franchise Analysis Project**!  
This project dives deep into a dataset of movie franchises to uncover insights on:

- 🎬 Franchise popularity  
- 💰 Budget vs. box office performance  
- ⭐ Audience ratings  
- 📈 Predicting gross revenue using machine learning

Whether you're a movie buff or a data science enthusiast, this project showcases how real-world data can be transformed into actionable insights through **Python**, **visualization**, **statistics**, and **predictive modeling**.

Explore how franchise films perform and what makes them successful using tools like `pandas`, `seaborn`, and `scikit-learn`.
